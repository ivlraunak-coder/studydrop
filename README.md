# StudyDrop — Final Modular Build

A modular, no-AI StudyDrop frontend using Firebase Authentication + Realtime Database.

## Deploy
Upload the complete folder structure to GitHub and connect the repository to Vercel. Do not upload `.env` files, API secrets, or an old AI backend.

Enable Firebase Anonymous Authentication and publish `database.rules.json` in Realtime Database Rules.
